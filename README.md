# KotVPN для Windows — загрузки

Здесь лежат готовые версии **KotVPN для Windows** — VPN-клиента на ядре Xray.

## Как установить

1. Откройте [последний релиз](../../releases/latest) и скачайте **KotVPN.exe**.
2. Запустите файл. При первом запуске Windows может показать «Windows защитила ваш компьютер» —
   нажмите **«Подробнее» → «Выполнить в любом случае»** (у программы пока нет цифровой подписи).

Обновления KotVPN находит и ставит сам: когда выходит новая версия, появляется окно «Доступно обновление».
